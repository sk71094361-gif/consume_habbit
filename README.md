# 살까말까?

대학생 소비 의사결정 서비스. 구매 판단, 이메일 회원 인증, 계정별 판단 기록, 위시리스트, 구매·보류 선택, 월별 소비 리포트를 제공합니다.

## 배포
`index.html`, `salka-service.js`, `salka-service.css`를 같은 디렉터리에 배포하세요. 별도 빌드 명령은 필요하지 않습니다. HTTPS 환경에서 이용하세요.

## 공개 운영 전 필수 설정
- 전용 Supabase 프로젝트: `lyrpqmgmdhkgkwgsmkfy` (`salka-malka`)
- Authentication > URL Configuration: Site URL과 허용 Redirect URL에 실제 배포 주소를 설정해야 합니다. 현재 확인된 설정은 localhost 기본값입니다.
- 인증 메일 발송용 SMTP와 검증된 발신자를 설정해야 합니다. 기본 메일 발송은 대상 및 발송량 제한이 있어 공개 운영용으로 적합하지 않습니다.
- 이메일 확인은 필수이며, 실제 메일 수신과 가입·로그인 왕복은 아직 미검증입니다.
- Vercel 배포 완료 상태는 아직 확인하지 않았습니다.

## 데이터와 보안
`purchase_records` 테이블에 RLS를 적용했습니다. 로그인한 사용자는 본인 기록만 조회·변경·삭제할 수 있습니다. 점수와 선택 날짜는 DB 트리거에서 계산합니다. 비회원 분석은 저장하지 않습니다. 브라우저에는 publishable key만 사용하며, DB 비밀번호나 service_role 키를 커밋하지 마세요.

## 집계
고민 횟수는 저장된 기록 생성 월, 구매·보류는 선택 날짜의 월 기준입니다(Asia/Seoul). 구매와 보류는 상호 배타적이며 상태를 바꾸면 기존 집계에서도 빠집니다. 보류 금액은 실제 저축액이 아닌 구매를 참은 상품 가격입니다. 결정 3건 이상인 월부터 참고용 소비습관 점수를 표시합니다.

## 검증
DOM 에뮬레이션에서 입력·결과·변경 후 저장 차단, HTML 문자열 안전 출력, 월 경계 및 구매·보류 집계를 점검했습니다. 실제 DB에서 다른 계정의 조회·수정·삭제와 타인 소유자로 기록 생성을 차단하는지 검증했습니다. 실제 브라우저 화면 및 인증 메일 발송은 공개 전에 추가 점검해야 합니다.
