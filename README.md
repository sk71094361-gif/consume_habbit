# 살까말까?

대학생 소비 의사결정 서비스. 구매 판단, 이메일 회원 인증, 계정별 판단 기록, 위시리스트, 구매·보류 선택, 월별 소비 리포트를 제공합니다.

## 배포
아래 다섯 파일을 같은 디렉터리에 배포하세요. 별도 빌드 명령은 필요하지 않으며 HTTPS 환경에서 이용하세요.

- index.html
- salka-service.css
- salka-service.js
- refinement.css
- refinement.js

## 디자인 개선
아이보리·딥 네이비 중심의 카드 UI, 대형 구매 적정도 그래프, 점수 구성 비교, 오늘의 소비 한마디를 적용했습니다. 상세 변경 및 검증 내용은 DESIGN.md를 참고하세요. 기존 인증 및 기록 저장 로직은 유지했습니다.

## 공개 운영 전 필수 설정
전용 Supabase 프로젝트는 `lyrpqmgmdhkgkwgsmkfy` (`salka-malka`)입니다.
- Authentication > URL Configuration에서 Site URL과 허용 Redirect URL에 실제 배포 주소를 설정해야 합니다.
- 인증 메일 발송용 SMTP와 검증된 발신자를 설정해야 합니다. 기본 메일 서비스는 발송 대상과 발송량이 제한됩니다.
- 이메일 확인은 필수이며 실제 메일 수신 및 가입·로그인 왕복은 아직 미검증입니다.
- GitHub 저장과 실제 Vercel 배포 완료는 별개입니다. 배포 상태는 별도로 확인해야 합니다.

## 데이터와 보안
purchase_records에 RLS를 적용하여 본인 기록만 조회·변경·삭제하도록 제한했습니다. 점수와 선택 날짜는 DB 트리거에서 계산합니다. 브라우저에는 publishable key만 사용하며, DB 비밀번호나 관리자용 키는 커밋하지 마세요.

## 집계 기준
고민 횟수는 저장된 기록 생성 월, 구매·보류는 선택 날짜의 월 기준입니다(Asia/Seoul). 구매와 보류는 상호 배타적이며 상태를 변경하면 기존 집계에서도 빠집니다. 보류 금액은 실제 저축액이 아닌 구매를 참은 상품 가격입니다. 결정 3건 이상인 월부터 참고용 소비습관 점수를 표시합니다.
